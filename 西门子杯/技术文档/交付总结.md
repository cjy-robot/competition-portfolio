# 车牌检测+识别 MCU 部署 — 交付总结

## 项目目标

CCPD 中国车牌检测 + 识别，部署到 **GD32H759IMK6 MCU**（2MB Flash, 1MB SRAM），OV2640 摄像头采集。

流水线：`OV2640拍照 → 192×192缩放 → YOLO检测车牌 → 原图裁剪 → 94×24灰度 → LPRNet识别 → 7位车牌号`

### 模型接口

```
输入:  [1, 192, 192, 3]  int8  scale=0.003922  zp=-128
输出0: [1, 12, 12, 16]   int8  scale=0.003922  zp=-128  (stride=16, 小anchor)
输出1: [1, 6,  6,  16]   int8  scale=0.003922  zp=-128  (stride=32, 大anchor)

16通道布局: ch0-11=3anchor×4reg, ch12-14=3obj, ch15=shared_cls
值域: 全部已sigmoid [0,1]
```

### Anchors

```
Head0 (stride=16): [31.24,8.24] [54.07,13.34] [49.55,24.23]
Head1 (stride=32): [77.18,18.28] [69.73,35.59] [114.20,31.10]
```

### 解码公式

```
cx = (tx*2 - 0.5 + gx) * stride
cy = (ty*2 - 0.5 + gy) * stride
bw = (tw*2)^2 * aw
bh = (th*2)^2 * ah
conf = obj * cls
```

## 技术要点（交接必读）

### 为什么之前的做法不行

- **onnx2tf 不兼容 ShuffleNetV2**：channel shuffle 的 reshape→transpose→reshape 在 onnx2tf 转换时精度全丢（diff 0.5+）
- **ONNX Runtime QDQ 不能转 TFLite**：GD32 GUI 底层是 onnx2tf，不认识 QDQ 的 QuantizeLinear/DequantizeLinear 节点
- **ai_edge_torch 在 Windows 上不可用**：依赖 `torch_xla`，无 Windows 版

### 正确做法

```
PyTorch 权重 → Keras 重建模型 → TF TFLiteConverter → INT8 TFLite
```
完全绕开 ONNX 和 onnx2tf。TF 原生工具对 ShuffleNetV2 的所有 op 处理正确。

### 环境

- `yolo-fastest`: F:\Anaconda_envs\envs\yolo-fastest\ (torch 2.6, TF 2.21, 用于训练)
- `tf-convert`: F:\Anaconda_envs\envs\tf-convert\ (torch 2.6+cpu, TF 2.13, 用于 TFLite 转换)
- PT 权重导出: `yolo-fastest` env 运行 → 生成 `pt_weights.npz`
- Keras 权重迁移: `tf-convert` env 运行 `yolo_keras_weight_transfer.py`
- TFLite 导出: `tf-convert` env 运行量化脚本
